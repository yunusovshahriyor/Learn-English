# Learn-English

Дарсҳои забони англисӣ бо муаллими шахсӣ.

- [`CLAUDE.md`](CLAUDE.md) — қоидаҳои дарс: тартиби дарс, забон, талаботи муаллим.
- [`GRAMMAR.md`](GRAMMAR.md) — қоидаҳои грамматика аз дарсҳои гузашта.
- [`PROGRESS.md`](PROGRESS.md) — рӯзнома: мавзӯъҳо, калимаҳо, ҷойҳои заиф, вазифаи хонагӣ.
- [`audio/`](audio) — аудиои калимаҳо.

Барои дарс «урок» ё «мини» нависед.
